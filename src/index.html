LEARNING NOTE

Insertion Sort

左側の整列済み部分へ、次の値を正しい位置まで差し込みます。

観察ポイント

ほぼ整列済みの入力では、値をずらす回数が少なくなることに注目しましょう。

この実装の計算量

最良
O(n)
平均
O(n²)
最悪
O(n²)
性質
安定・in-place
